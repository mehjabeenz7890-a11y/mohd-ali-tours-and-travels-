  images/gallery/gallery-2.jpg    -> gallery photo 2
  images/gallery/gallery-3.jpg    -> gallery photo 3
  images/gallery/gallery-4.jpg    -> gallery photo 4
  images/gallery/gallery-5.jpg    -> gallery photo 5
  images/gallery/gallery-6.jpg    -> gallery photo 6

Favicon: index.html points its <link rel="icon"> at images/ma-logo.jpg,
so dropping the logo file in place also sets the favicon automatically.
For best results use a roughly-square version of the logo.
